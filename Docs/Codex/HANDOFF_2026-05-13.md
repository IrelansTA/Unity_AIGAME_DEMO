## Runtime Art Convention

- Runtime sprite folders:
  - `Assets/Art/Generated/Hero/V2Aligned`
  - `Assets/Art/Generated/Enemy/V2Aligned`
- All runtime actor PNGs keep existing `.meta` files and GUIDs.
- Canvas: `192x192`
- Import: Sprite, Single, PPU `64`, pivot `Center`
- Visual anchor:
  - Body center target: `x=95.5`
  - Ground/body bottom target: `bottom=149`
- Do not equalize bbox height across actions. Preserve action pose height; align feet/body bottom and center instead.
- Exception: for the hero no-bob run cycle, align the run body/head top line to `top=83` so the torso does not bounce.
